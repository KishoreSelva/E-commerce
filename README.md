# E-Commerce Website

This is a simple e-commerce web application built using **FastAPI** as the backend and **Jinja templates** for server-side rendering. The frontend is designed with **HTML, CSS, and JavaScript**, and **PostgreSQL** is used as the database.

## 🚀 Features
- User authentication (Signup/Login)
- Product listing and search functionality
- Shopping cart management
- Order processing
- Secure payment integration (optional)
- Admin dashboard for managing products and orders

## 🛠️ Tech Stack
- **Backend**: Python, FastAPI
- **Frontend**: Jinja Templates, HTML, CSS, JavaScript
- **Database**: PostgreSQL
- **Tools**: VS Code

## ⚡ Installation & Setup
1. **Clone the repository**
   ```sh
   git clone https://github.com/KishoreSelva/E-commerce.git
   
2. Create a virtual environment

   python -m venv venv
   source venv/bin/activate
  
3. Install dependencies

   pip install -r requirements.txt

4. Set up your database
   
5. Run the application

   uvicorn app.main:app --reload
